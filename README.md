# Royal Enfield Bike Showcase

A responsive and interactive website developed as part of my second-year B.Tech Information Technology summer internship project at Royal Enfield. The website allows users to explore different Royal Enfield motorcycle models, view their specifications, and customize the bike preview using an interactive color picker.

## Features

- **Bike Model Catalog:** Explore six motorcycle models: Classic 350, Bullet 350, Hunter 350, Meteor 350, Himalayan, and Interceptor 650.
- **Model Details:** Click a model to view its engine capacity, riding style, recommended use, and description.
- **Interactive Color Picker:** Change the bike preview between Royal Red, Stealth Black, Forest Green, Midnight Blue, and Desert Gold.
- **Responsive Design:** Designed to adapt to desktop and mobile screens.
- **Smooth Navigation:** Navigate between Home, Models, Color Picker, and About sections.
- **Animations and Hover Effects:** Includes fade-in animations and interactive catalog cards.

## Technologies Used

- HTML5 — website structure
- CSS3 — custom styling, bike illustration, animations, and responsive layout
- Tailwind CSS — utility-based styling
- JavaScript — dynamic model selection and color customization

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the HTML file in a web browser.
4. Browse the motorcycle catalog and click different models to view their details.
5. Use the color picker to change the bike preview.

No backend or database setup is required. The project runs entirely in the browser and loads Tailwind CSS through a CDN, so an internet connection is needed for that styling dependency.

The purpose of this project was to develop an interactive motorcycle showcase website that presents Royal Enfield models in a simple and engaging way while applying my knowledge of web development.
